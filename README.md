# Homebrew Ursine

Homebrew tap for [ursine-code](https://github.com/ursine-code) formulae.

## Install

```sh
brew tap minademian/ursine
brew install yarn-shell-completion
```

## Formulae

| Formula | Description |
|---------|-------------|
| `yarn-shell-completion` | Bash and Zsh completion for Yarn 4+ |

## Troubleshooting

```sh
brew update
brew doctor
```

To report issues, visit [github.com/minademian/homebrew-ursine/issues](https://github.com/minademian/homebrew-ursine/issues).
